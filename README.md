# 🌿🐦 TaiaoDex

**TaiaoDex** is a Flutter mobile app that catalogues native New Zealand bird species, inspired by a Pokédex-style interface.

It combines my passion for animals, Pokémon, and software engineering to create a beautiful, educational biodiversity app focused on Aotearoa’s unique wildlife.

---

## ✨ Features

* 🐦 Native New Zealand bird database
* 🌿 Māori names + scientific names
* 📊 Conservation status tracking
* 📱 Cross-platform (iOS, Android, Web, Desktop)
* 🔍 Search and filtering (planned)
* 📍 Map sightings integration (planned)
* 🤖 Future AI bird identification using computer vision

## 🚀 Getting Started

### 1. Clone the repo

```bash
git clone https://github.com/philip1304/taiaodex.git
cd taiaodex
```

### 2. Install dependencies

```bash
flutter pub get
```

### 3. Run the app

iOS Simulator:

```bash
flutter run -d "iPhone 16 Plus"
```

Android Emulator:

```bash
flutter run -d android
```

Web:

```bash
flutter run -d chrome
```

## 🌏 Motivation

As a Computer Science student in New Zealand with a passion for Pokémon and animals, I wanted to build something that connects technology with biodiversity education.

New Zealand’s birds are globally unique, and TaiaoDex aims to make learning about them fun, accessible, and interactive.
